# Calculadora Interativa em JavaScript

Projeto desenvolvido para praticar e consolidar conceitos fundamentais e intermediários de **JavaScript moderno (ES6+)**, com foco em lógica de programação e estruturação de código.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da interface.
* **CSS3:** Estilização responsiva e design limpo com variáveis CSS (`:root`).
* **JavaScript (Vanilla):** Lógica da aplicação, manipulação do DOM e Factory Functions.

## 🧠 Conceitos Praticados

* **Factory Functions:** Padrão de projeto para criação e encapsulamento de objetos (separando o que é público e privado).
* **Manipulação do DOM:** Captura de cliques, eventos de teclado (`keyup`) e atualização dinâmica do display.
* **Escopo e Contexto (`this` & Arrow Functions):** Gerenciamento correto do contexto de execução.
* **Tratamento de Erros (`try/catch` & `eval`):** Validação de entradas e prevenção de quebras na aplicação.

## 💡 Sobre o Projeto
> Projeto prático desenvolvido durante o curso **"JavaScript e TypeScript do básico ao avançado"** (do professor Luiz Otávio Miranda na Udemy), servindo como parte dos meus estudos e evolução em desenvolvimento web.

## 💻 Como Executar o Projeto

1. Clone este repositório ou faça o download dos arquivos.
2. Abra a pasta do projeto no seu editor de código (como o **Visual Studio Code**).
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência (ou utilize a extensão *Live Server*).
